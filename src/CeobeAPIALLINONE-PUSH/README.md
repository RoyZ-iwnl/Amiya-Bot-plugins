# CeobeAPI聚合推送系统

基于CeobeAPI的多平台聚合推送系统，支持微博、B站、网易云音乐、明日方舟等多个平台的内容自动推送。

## 功能特性

- 🌟 **多平台支持**: 微博、B站、网易云音乐、明日方舟游戏、明日方舟官网
- 🎯 **灵活订阅**: 用户可自由选择感兴趣的数据源进行订阅
- 🔄 **自动推送**: 定时检查更新，自动推送最新内容到群组
- 📱 **平台适配**: 针对不同聊天平台优化消息格式
- 🛡️ **内容过滤**: 支持正则表达式屏蔽规则
- 📊 **防重推送**: 数据库记录防止重复内容推送
- 🎨 **图片优化**: 自动下载并处理图片，支持微信GIF压缩

## 配置

前往控制台 >> 插件管理 >> 插件配置，管理聚合推送设置

### 主要配置项

- `enableAggregator`: 启用聚合推送功能
- `checkRate`: 内容检查频率（秒）
- `imagesCache`: 图片缓存目录
- `maxImagesPerPost`: 每条内容最大图片数
- `debugCeobeAPI`: 开启调试模式
- `supportedPlatforms`: 支持的平台列表

## 兼容性

本插件完全兼容原有微博推送功能，同时新增聚合推送系统。用户可以继续使用原有的微博命令，也可以使用新的聚合推送功能。
