##### 本插件依赖【明日方舟数据解析】插件，且需要及时更新游戏数据才能保证准时提醒
### 支持提醒活动开始、活动结束、活动奖励兑换结束。
- 仅支持游戏内活动的提醒

- 由管理员开启活动提醒
    - 发送`兔兔开启活动提醒`以开启本群或本频道活动提醒推送
    - 发送`兔兔关闭活动提醒`以关闭本群或本频道活动提醒推送

- 发送`兔兔活动列表`可查看近期活动及卡池的开启关闭信息

### 配置

- 前往控制台 >> 插件管理 >> 插件配置，管理提醒推送设置

### 手动更新数据

- 可从[该仓库](https://github.com/Kengxxiao/ArknightsGameData)的'zh-CN/gamedata/excel'目录下载最新的json文件，替换Amiya-Bot/resource/gamedata/gamedata/excel目录下的同名文件，然后在控制台的插件管理中选择本插件，点击右上角的“重载插件”来实现手动更新数据。

- 需要替换的文件包括：
    - activity_table.json（包含活动信息）
    - crisis_v2_table.json（包含危机合约信息）
    - gacha_table.json（包含卡池信息）
    - climb_tower_table.json （包含保全派驻周期信息）

- 注意重启Amiyabot或明日方舟数据解析插件将导致手动更新失效，需要重新进行手动更新。
