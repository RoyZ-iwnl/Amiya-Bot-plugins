# 使用说明

## 聚合推送功能（推荐）

### 开启聚合推送
管理员发送 `兔兔开启聚合推送` 进入数据源选择界面，可以选择多个感兴趣的数据源：

**支持平台：**
- 🐦 **微博** - 明日方舟、明日方舟朝陇山、明日方舟终末地等官方微博
- 📺 **B站** - 明日方舟官方、各UP主动态
- 🎵 **网易云音乐** - 明日方舟官方歌单、音乐动态
- 🎮 **明日方舟游戏** - 游戏内公告、活动信息
- 🌐 **明日方舟官网** - 官方新闻、公告

**操作步骤：**
1. 管理员发送 `兔兔开启聚合推送`
2. 系统显示按平台分组的数据源菜单
3. 回复数字选择数据源（多个用逗号分隔，如：1,3,5）
4. 系统确认订阅，开启自动推送

### 管理聚合推送
- `兔兔关闭聚合推送` - 关闭群组的聚合推送功能
- `兔兔最新内容` 或 `兔兔最新聚合` - 手动获取最新聚合内容

---

## 推荐使用方式

1. **新用户**：建议直接使用聚合推送功能，可以一次性订阅多个平台的内容
2. **现有用户**：可以继续使用原有微博命令，同时可以尝试新的聚合推送功能
3. **内容丰富**：聚合推送支持更多平台，内容更加丰富全面
4. **管理便捷**：一个命令即可管理所有订阅，无需分别设置
